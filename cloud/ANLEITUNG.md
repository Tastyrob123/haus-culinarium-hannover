# So schickt Robert ein neues Haus in die Cloud

Du baust Recherche, Konzept und Website. Alles danach (Werkbank, die sieben Werkzeuge, Drucksachen, alle Prüfungen) läuft in der Cloud. Dein Mac rechnet dabei nicht mit.

## 1. Haus hochschicken (einmal, ca. 20–40 Minuten Hochladen)
Sag in einem Chat auf dem Mac: **«Schick <Haus> in die Cloud.»** Der Chat führt aus:
```
~/Cloud-Haeuser/culinarium-hannover/cloud/neues-haus.sh "<Hausordner>" <kurzname>
```
Damit entsteht ein privater Ordner auf GitHub (`Tastyrob123/haus-<kurzname>`), mit Website, Werkbank-Rahmen, Prüfwerkzeugen. Alte Prüfbilder, Sicherungen und Schlüssel bleiben auf dem Mac.

## 2. Cloud-Chat starten
Auf claude.ai/code eine neue Sitzung, Umgebung **«Default»**, Ordner `haus-<kurzname>`. Erster Satz: **«Du bist Oberchef. Bau nach CLAUDE.md alles bis grün.»**
Der Chat liest die Regeln im Ordner (CLAUDE.md), baut Werkbank, Werkzeuge und Drucksachen und lässt jeden Stand prüfen.

## 3. Was in der Cloud passiert
- Jeder Stand wird auf viele Rechner gleichzeitig verteilt: jedes Werkzeug in mehreren Teilen, jede Breite (1440, 1280, 1000, 390), Chromium und WebKit, dazu die Bewegung.
- Die Bilder und Funde kommen zurück, der Chat sieht sie sich an, repariert und prüft neu, bis alles grün ist.
- Jedes Grün gilt nur für genau diesen Stand. Neues kommt erst nach einem grünen Lauf in den Hauptstand; der vorige Stand ist immer mit einem Klick zurückholbar.

## 4. Was du bekommst
Eine Nachricht mit einem Link: Übersicht, Abdeckungstafel je Werkzeug, Messlauf-Tafel, Dauer. Spätestens nach einem Tag.

## Kosten
GitHub rechnet die Rechner-Minuten ab. Im Konto sind 2.000 Minuten im Monat frei; darüber kostet jede Minute 0,006 US-Dollar. Die gemessenen Zahlen für Culinarium stehen unten.
